# Getting Started

This guide walks you from installation to a production-style first extraction.

## Prerequisites

- Go 1.25+
- Familiarity with Go modules

## Install

```bash
go get github.com/halas77/goscrape
```

## Step 1: Parse HTML from a string

Use this pattern in tests, prototypes, and fixtures:

```go
package main

import (
  "fmt"

  "github.com/halas77/goscrape/engine"
)

func main() {
root, err := engine.InitDocument(`<div><h2 class="name">Neural Link V1</h2></div>`)
if err != nil {
  panic(err)
}

name := root.SelectFirst("h2.name")
fmt.Println(name.Text()) // Neural Link V1
}
```

## Step 2: Parse HTML from a URL

Use `LoadDocument` when you need a one-liner for fetching + parsing:

```go
root, err := engine.LoadDocument("https://example.com")
if err != nil {
  panic(err)
}

title := root.SelectFirst("title")
fmt.Println(title.Text())
```

## Step 3: Build your first extraction flow

Map selector expressions into a stable data shape:

```go
cards := root.SelectAll(".product-item")
mapped := cards.Map(map[string]string{
  "sku":   "@data-sku",
  "name":  "h3.name",
  "price": "span.price",
  "url":   "a.link @href",
})

jsonData, _ := engine.ExportJSON(mapped)
fmt.Println(string(jsonData))
```

## Step 4: Write data to disk

```go
_ = engine.WriteMappedJSON("products.json", mapped)
_ = engine.WriteMappedCSV("products.csv", mapped)
_ = engine.WriteMappedMD("products.md", mapped)
```

## Practical tips

- Prefer specific selectors (`.product-item h3.name`) over broad selectors (`h3`)
- Keep one mapping per page type to simplify maintenance
- Validate fields (`price`, `url`, `sku`) before exporting
- Start with fixture HTML in tests, then switch to live pages
