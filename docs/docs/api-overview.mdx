# API Overview

This page summarizes the most important `nano scrape` APIs and where each one fits in a real scraper.

## Document Initialization

- `engine.InitDocument(input any)`
  - Parses local HTML (`string` or `[]byte`)
- `engine.LoadDocument(url string)`
  - Fetches remote HTML and parses it in one step

Use `InitDocument` for tests and fixtures, `LoadDocument` for quick remote extraction flows.

## Selection APIs

### CSS-style selection

- `Select(selector string, f func(*Tag))`
- `SelectAll(selector string) *Tags`
- `SelectFirst(selector string) *Tag`

Choose this set when you want concise, frontend-like selectors.

### Tag and attribute selection

- `Find(name string, attrs []*Attribute, cb TagCallback)`
- `FindAll(name string, attrs ...[]*Attribute) *Tags`
- `FindFirst(name string, attrs ...[]*Attribute) *Tag`

`FindAll` is useful when you want explicit, strict filters:

```go
attrs := []*engine.Attribute{
  {Key: "data-category", Value: "electronics"},
}
items := root.FindAll("article", attrs)
```

Use this set when you need stricter and more explicit matching logic.

## Navigation APIs

- `Next()` and `Previous()` to traverse sibling nodes
- `Parent()` to move upward in the tree
- `FirstChild()` and `LastChild()` for nested traversal

These are useful for scraping patterns like “find title, then jump to nearest price node.”

## Mapping and transformation

- `Map(mapping map[string]string)` on `*Tags`

This creates a predictable schema from each selected node:

```go
mapping := map[string]string{
  "sku":   "@data-sku",
  "name":  "h3.name",
  "price": "span.price",
  "url":   "a.link @href",
}

rows := root.SelectAll(".product-item").Map(mapping)
```

## Text & Print

- `Text()` returns concatenated nested text
- `Print()` pretty-prints the node subtree

These are ideal for debugging selectors and inspecting intermediate extraction output.
