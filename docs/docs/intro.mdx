# nano scrape Documentation

Welcome to the official documentation for `nano scrape` — a pragmatic Go library for extracting structured data from HTML.

Whether you are collecting product data, generating market reports, or enriching internal datasets, `nano scrape` gives you a compact API that stays readable as your scraper grows.

## Why nano scrape

- **Fast onboarding**: parse HTML from raw strings or URLs in a few lines
- **Flexible extraction**: combine CSS selectors with strict tag/attribute matching
- **Scraping-ready HTTP layer**: custom headers, cookies, POST helpers, and proxy rotation
- **Export-friendly output**: JSON, CSV, and Markdown for easy downstream use

## Installation

```bash
go get github.com/halas77/goscrape
```

## 30-second example

```go
package main

import (
  "fmt"

  "github.com/halas77/goscrape/engine"
)

func main() {
  html := `<main><span class="price">$899.99</span></main>`

  root, err := engine.InitDocument(html)
  if err != nil {
    panic(err)
  }

  price := root.SelectFirst(".price")
  fmt.Println(price.Text()) // $899.99
}
```

## Typical workflow

1. **Load HTML** from a string or URL
2. **Select elements** with CSS or explicit filters
3. **Map fields** into a consistent schema
4. **Export results** to your preferred format
